# The Open Microsoft Project

Реверс-инжиниринг продуктов Microsoft в код на Rust (лицензия GNU GPLv3).

## О проекте

Здесь собраны независимые реализации утилит и системных программ, вдохновленных продуктами Microsoft и написанных с нуля на Rust с использованием `egui`.

Основная идея — брать привычные десктопные инструменты, избавляться от раздутых веб-технологий и тяжелых зависимостей, переписывая их в виде быстрых, легких и нативных приложений. Каждый репозиторий ориентирован на чистую архитектуру, минимальное потребление ресурсов и понятный, детально прокомментированный код.

## Принципы

* **Нативная производительность:** Написано на Rust с упором на скорость работы и безопасность памяти.
* **Без лишнего веса:** Прямой рендеринг интерфейса без громоздких сторонних рантаймов.
* **Читаемость кода:** Логика компонентов, состояний и парсеров подробно задокументирована.
* **Открытый код:** Проекты распространяются под лицензией GNU GPLv3.

## Лицензия

Все проекты в рамках The Open Microsoft Project распространяются под условиями лицензии GNU GPLv3.

# The Open Microsoft Project

Reverse engineering Microsoft products into Rust code (GNU GPLv3 license).

## Overview

This organization hosts independent, clean-room implementations of software inspired by Microsoft products, rewritten from scratch in Rust using `egui`.

The core idea is simple: take familiar desktop utilities and system tools, strip out bloat, web-technologies, and heavy dependencies, and replace them with fast, lightweight, and native applications. Every repository in this project focuses on clean architecture, minimal resource usage, and heavily commented, readable code designed for transparency and learning.

## Principles

* **Native Performance:** Written in Rust for maximum execution speed and safety.
* **No Bloat:** Direct rendering and UI management without heavy frameworks.
* **Code Clarity:** Every component, state machine, and resource parser is thoroughly documented and commented.
* **Open Source:** Licensed under the GNU GPLv3 to ensure code remains free and open for everyone.
